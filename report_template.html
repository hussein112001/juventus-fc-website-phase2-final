1. Executive Summary

This report documents the development of the Juventus FC web portal for Phase 2 of the CSCI390 course. The project involves a complete transition from static HTML to a modern, dynamic ReactJS application. The focus was on creating a professional, responsive, and high-performance frontend using the latest industry standards.

2. System Design

The application follows a modular, component-based architecture to ensure scalability and ease of maintenance. Key architectural decisions include:

  • Component-Based UI: Reusable elements like Navigation, Footer, and Player Cards.
  • Client-Side Routing: Seamless page transitions without browser reloads using Wouter.
  • Type-Safe Development: Using TypeScript to prevent runtime errors and improve code quality.
  • Responsive Grid: A mobile-first approach using Tailwind CSS for all device sizes.

6. Challenges & Solutions

One of the primary challenges was migrating the static assets from Phase 1 into a React-friendly structure while maintaining the brand's visual integrity. This was solved by implementing a robust asset management system and using CSS variables for consistent branding.
